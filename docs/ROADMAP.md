# Battery RUL Lab roadmap

1. Freeze the data contract and implement a deterministic baseline.
2. Add a documented dataset adapter and leakage-safe split.
3. Compare advanced models with ablations and error slices.
4. Add uncertainty, robustness, and model-card documentation.
5. Package a typed inference interface and monitoring plan.

The immediate milestone is: Add licensed battery adapters, sequence features, bootstrap intervals, and a model card.
